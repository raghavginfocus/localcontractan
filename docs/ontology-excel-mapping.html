What is contract-clauses.ttl and how does it relate to contract.owl?

Both files live at agents/src/agents/ingestion/new_ontology/ and are loaded at runtime via config.py. They model the same domain but serve different purposes:

contract.owl OWL ontology — defines the vocabulary: classes, object & datatype properties, cardinality restrictions, named individuals for ClauseType and EntityType. Loaded by the reasoning agent to build the knowledge graph and run OWL inference.
contract-clauses.ttl Turtle = OWL + SHACL — re-declares the same ontology in compact Turtle syntax and adds SHACL shapes for validation. Loaded by the ingestion pipeline to validate that every extracted ContractFile, Clause, and Entity satisfies structural constraints (min/max counts, allowed clause types via sh:in lists).

Key difference: contract.owl is the authoritative ontology used for reasoning. contract-clauses.ttl is a Turtle serialisation of the same ontology plus SHACL validation shapes. When both are loaded, SHACL catches malformed RDF triples before they enter the triplestore.

Important overlap: contract-clauses.ttl uses proc:clauseText while the SHACL shapes in contract_shapes.ttl (under schemas/shacl/) use proc:rawText — these are inconsistent and will cause SHACL validation gaps if both files are used together.
